## Problem

Score : 100 points

Problem Statement

You are given integers A and B between 1 and 9, inclusive.

Find the number of digits in the value of A+B.

Constraints

- A and B are integers between 1 and 9, inclusive.

Input

The input is given from Standard Input in the following format:

```
A B
```

Output

Print the answer.

Sample Input 1

```
4 9
```

Sample Output 1

```
2
```

4+9=13, and 13 is a 2-digit number.

Sample Input 2

```
7 1
```

Sample Output 2

```
1
```

7+1=8, and 8 is a 1-digit number.

Sample Input 3

```
7 3
```

Sample Output 3

```
2
```

7+3=10, and 10 is a 2-digit number.
